# sys-lib v0.5.1 - Documentation on Every Platform

**A documentation fix: docs.rs shows the Windows and macOS items again.** No code changed.

## What changed

- docs.rs built only the Linux documentation for 0.5.0. Its Windows and macOS builds failed in blake3's build script, which the `device-id` feature brings in through crypt-io: the script compiles C and assembly for the target, and docs.rs has no compiler for Windows or macOS. The docs.rs settings now have blake3 build its portable Rust code, which documents the same. Builds anywhere else are unaffected.
- The 0.5.0 changelog entry now carries the day it was published.

## Upgrading

Nothing to do: 0.5.1 is the same library as 0.5.0. The 0.5.0 release notes describe what it contains.

```toml
[dependencies]
sys = { package = "sys-lib", version = "0.5" }
```
