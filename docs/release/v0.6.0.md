# sys-lib v0.6.0 - Environment and Reports

**Feature complete.** sys-lib now tells a service whether the machine it starts on is fit to serve, whether a benchmark run on it can be trusted, and how it is secured, and it runs on FreeBSD and 32-bit Linux. Versions 0.7 to 1.0 optimise and harden; the API is in `docs/API.md`.

## Server readiness

```rust
use sys_lib::readiness::{self, Profile};

let report = readiness::report_for(Profile::Database, "/var/lib/app");
println!("{report}");
if !report.passed() { /* refuse to start, or log loudly */ }
```

Transparent huge pages, swappiness, overcommit, map count, write-back, NUMA balancing, open-file and locked-memory limits, listen backlog, ephemeral ports, CPU frequency policy, clock source and synchronisation, swap, and the data directory's filesystem, access times, free space, storage kind, and I/O scheduler. Each check gives what it found, what the profile wants, why it matters, and the command that changes it. sys-lib never changes a setting. A check that does not apply on the OS is left out; one it cannot read is `Unknown` with the reason.

## Benchmark environment and security posture

`bench::environment()` prints next to a result what could make it noisy: a power-saving governor, turbo, throttling, battery, load, a VM, or an unstable clock. `is_reproducible()` says whether any of that applies. `security::posture()` reports Secure Boot, the TPM, disk encryption, SELinux or AppArmor, ASLR, lockdown or VBS, code integrity, the firewall, and the CPU vulnerabilities the kernel lists. Each value is what the OS says, never a guess.

## Temperatures, GPUs, probes

- `sensors::temperatures()` reads Linux hwmon, Windows drives, and FreeBSD sensors.
- `gpu::list()` names the graphics adapters on Linux, macOS, and Windows.
- `probe::Probe::with_root("/host")` lets a containerised monitoring agent read the host. The root is given in code, so no environment variable can redirect another program's readings.

## Platforms

- **FreeBSD.** A new backend, tested in a FreeBSD 14 virtual machine on every change.
- **32-bit Linux.** glibc on i686 and armv7, with every structure layout checked against libc and the full suite run in CI.
- **iOS.** `mem::free()` now uses the app's own memory budget.
